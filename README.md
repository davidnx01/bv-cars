# BV Cars — neoficiálny návrh homepage

> Neoficiálny návrh — nie je to oficiálny web podniku. Ukážka od [webdavid.sk](https://webdavid.sk); objednávky ani rezervácie tu nefungujú.

Servis BMW a MINI Bratislava | BV Cars – diagnostika, prevodovky, opravy

Statická stránka bez build kroku — otvorte `index.html` v prehliadači.

## Štruktúra
- `index.html` — celá stránka (JSON-LD AutoRepair + FAQPage, živý stav otvorené/zatvorené, mapa až po kliknutí)
- `assets/css/style.css` — štýly (tokeny → základ → sekcie → responzívne)
- `assets/img/` — fotky vo WebP (vlastné fotky podniku + fotky z Unsplash, pozri nižšie)
